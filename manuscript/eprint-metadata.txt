Title
-----
Low-Memory SQIsign through Memory Reuse and Recomputation

Authors (in the same order as the paper)
-----------------------------------------
1. Name: Hiro Nakanishi
   Email: quantumsity@protonmail.com (public)
   Affiliation: Independent Researcher

Abstract (plain text for the submission form)
---------------------------------------------
SQIsign offers small public keys and signatures, but its key-generation and signing workspaces constrain microcontroller implementations. For SQIsign v2.0.1 Level I, we combine reuse of regions with disjoint lifetimes and recomputation of intermediate values. Instead of storing full-precision candidate norms, we retain only their bit lengths and leading 64 bits. We recompute both norms at full precision only when both fields agree between the two candidates being compared. This preserves the original comparison order without assuming a collision probability.

For Level I/RADIX32, the operation arena decreases from 353008 to 172080 bytes, a reduction of 51.25% relative to a static-arena implementation retaining full-precision norm tables. We execute key generation, signing, and verification on RP2350 without the GNU Multiple Precision Arithmetic Library (GMP), dynamic memory allocation, or external RAM, with a total SRAM reservation of 321408 bytes. Differential-conformance tests on 100 official inputs find matching outputs from ordinary and low-memory APIs built from the same commit. These tests do not compare against historical official known answers. Analysis of the fixed firmware bounds thread-mode stack use plus one maximum exception entry within its reservation. This excludes interrupt handlers, nesting, and interrupt-stack use at exception entry.

We also apply region reuse to two functions in SQIsign v3.0. Both function stack frames decrease across three parameter sets, and measured signing stack use decreases by 4664 bytes on RP2350 for one parameter set and one deterministic execution path. Partial norm storage and recomputation are specific to v2 and are not part of the v3 adaptation. These results demonstrate the effectiveness of region reuse and on-demand recomputation for reducing SQIsign workspaces, without establishing side-channel resistance or production readiness.
